# 📊 Base de Données - Exercices Pratiques

Bienvenue dans ce répertoire d'exercices pratiques sur les bases de données ! Ce projet contient des exercices progressifs couvrant les concepts fondamentaux des technologies de stockage de données.

## 📁 Structure du Projet

### 1. **Projet 1 - SQL Exercice** 🗄️
   - **Fichier**: `competition.sql`
   - **Objectif**: Maîtriser les concepts fondamentaux du SQL
   - **Contenu**: 
     - Création de tables pour une base de données de compétition
     - Requêtes SELECT, INSERT, UPDATE, DELETE
     - Opérations JOIN, agrégations et tris

### 2. **Projet 2 - NoSQL Exercice** 🌐
   - **Fichier**: `restaurants.sql`
   - **Objectif**: Comprendre les bases de données NoSQL
   - **Contenu**:
     - Structure de données pour une collection de restaurants
     - Opérations CRUD (Create, Read, Update, Delete)
     - Requêtes de filtrage et d'agrégation

## 🎯 Objectifs d'Apprentissage

✅ Comprendre les différences entre SQL et NoSQL  
✅ Maîtriser la création et la gestion de tables/collections  
✅ Écrire des requêtes complexes et performantes  
✅ Appliquer les bonnes pratiques de modélisation de données  

## 🚀 Comment Utiliser

1. **Pour SQL**: Importez le fichier `competition.sql` dans votre client SQL
2. **Pour NoSQL**: Chargez le fichier `restaurants.sql` dans votre base de données NoSQL

## 📝 Prérequis

- Un client SQL (MySQL Workbench, pgAdmin, etc.)
- Une base de données NoSQL (MongoDB, etc.)
- Connaissance basique en SQL

## 💡 Conseils

- Commencez par les exercices SQL avant le NoSQL
- Testez chaque requête individuellement
- Consultez la documentation officielle en cas de besoin
