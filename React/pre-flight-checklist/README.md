# Pre-flight Checklist

A modern React application for managing checklists and tasks efficiently.

## 📋 Project Documentation

### Download Project Details
[📄 Projet#1 Pre-flight checklist (Application web react).pdf](./public/Projet%231%20Pre-flight%20checklist%20(Application%20web%20react).pdf)

## 🚀 Features

- ✨ Modern and responsive UI with gradient design
- 📝 Create, read, update, and delete checklists
- ✅ Manage tasks within each checklist
- 🎨 Beautiful status badges (Pending, In Progress, Completed)
- 📱 Mobile-friendly design
- 🔐 Secure authentication
- ⚡ Fast performance with optimized API calls

## 🛠️ Tech Stack

- **Frontend:** React 18
- **Styling:** Tailwind CSS
- **HTTP Client:** Axios
- **Routing:** React Router v6
- **State Management:** React Hooks
- **API:** RESTful API

## 📦 Installation

```bash
# Install dependencies
npm install

# Start development server
npm start

# Build for production
npm run build
```

## 🔗 API Endpoints

- `POST /login` - User authentication
- `GET /checklists` - Fetch all checklists
- `POST /checklist/add` - Create new checklist
- `GET /checklist/:id` - Get specific checklist
- `POST /checklist/:id` - Update checklist
- `DELETE /checklist/delete/:id` - Delete checklist
